# ชั้นข้อมูลซ้อนบนแผนที่ (map overlays)

เอกสารนี้สำหรับคนทำหน้าเว็บ (module 01): ข้อมูลที่ใช้วาดซ้อนบนแผนที่ "ภาพรวม" นอกจากสีความเสี่ยงรายอำเภอ
ทุก endpoint อยู่ใต้ `/api` ของเว็บ (Next.js rewrite ไปที่ API `127.0.0.1:8002`) ดูรูปแบบเต็มได้ที่ `http://127.0.0.1:8002/docs`

| ชั้นข้อมูล | Endpoint | ชนิด | อัปเดต |
|---|---|---|---|
| ฝุ่น PM2.5 (สถานี) | `GET /v1/air/stations` | JSON list (มี `lat`, `lon`) | ทุก 15 นาที |
| เรดาร์ฝน | RainViewer tiles (ไม่ผ่าน API ของเรา) ดู `HazardMap.tsx` | raster tiles | ทุก 10 นาที |
| เขตน้ำท่วม (ดาวเทียม) | `GET /v1/map/overlays/flood` | GeoJSON polygons | ทุก 6 ชม. |
| พายุหมุนเขตร้อน | `GET /v1/map/overlays/cyclones` | GeoJSON polygons + lines + points | ทุก 15 นาที |
| คลื่นทะเล (ลูกศร) | `GET /v1/map/overlays/waves` | GeoJSON points | ทุก 6 ชม. |

ทุก overlay ตอบเป็น `FeatureCollection` และมีสองส่วนเพิ่ม:

- `overlay`: `status` (`ok` · `pending` = ยังโหลดครั้งแรกไม่เสร็จ ให้ถามใหม่ใน ~1 นาที · `unavailable` = ไม่มี key ของแหล่งข้อมูล), `updated_at` (UTC), `source` (ชื่อที่ต้องแสดงเป็นเครดิต)
- `generated_at`, `data_updated_at`, `degraded_services`, `inputs_pending`: เหมือน endpoint อื่น

กติกาที่ต้องคงไว้: **ระดับ (`level`) มาจาก `rules.yaml` เท่านั้น** หน้าเว็บห้ามคำนวณระดับเอง ให้ใช้สีตาม `LEVELS` ใน `lib/api.ts`
และแสดงเวลาของข้อมูลกับแหล่งที่มาทุกชั้นที่เปิดอยู่

## เขตน้ำท่วม — `/v1/map/overlays/flood`

อำเภอที่ดาวเทียม (GISTDA, Sentinel-1) เห็นน้ำท่วมใน 7 วันที่ผ่านมา เรียงพื้นที่น้ำท่วมมากไปน้อย
รูปร่างคือ**ขอบเขตอำเภอ** ไม่ใช่ขอบน้ำจริง (GISTDA ส่งขอบน้ำเป็นช่องหกเหลี่ยมเล็ก ๆ ~80,000 ช่องต่อสัปดาห์ ใหญ่เกินไปสำหรับเว็บ)

```json
{
  "type": "FeatureCollection",
  "features": [
    {"type": "Feature", "geometry": {"type": "Polygon", "coordinates": [[[100.41, 14.32], "..."]]},
     "properties": {"code": "TH1414", "name_th": "เสนา", "province_th": "พระนครศรีอยุธยา", "flood_km2": 12.4, "flood_share": 0.059}}
  ],
  "overlay": {"status": "ok", "window": "7days", "updated_at": "2026-10-22T09:10:00+00:00", "source": "GISTDA (ดาวเทียม Sentinel-1)"}
}
```

- `flood_km2`: พื้นที่น้ำท่วมโดยประมาณ (ตร.กม.) · `flood_share`: สัดส่วนของพื้นที่อำเภอ (0–1)
- แนะนำ: ลายเส้นทแยงหรือสีฟ้าโปร่งใส ความเข้มตาม `flood_share` เพื่อไม่ให้ทับสีระดับความเสี่ยงของชั้นหลัก

## พายุหมุนเขตร้อน — `/v1/map/overlays/cyclones`

พายุที่ GDACS ระบุว่ายังมีอยู่ในภูมิภาค ถ้าไม่มีพายุ `features` จะว่าง (`overlay.storms = 0`) ให้ซ่อนชั้นนี้และ legend ไปเลย

แยกชนิดด้วย `properties.kind`:

| `kind` | geometry | ความหมาย | แนะนำการวาด |
|---|---|---|---|
| `wind_area` | Polygon / MultiPolygon | พื้นที่ลมแรงตลอดเส้นทาง (รวมคาดการณ์) ต่อระดับลม `wind_kmh` = 63 / 93 / 119 กม./ชม. ขึ้นไป | fill โปร่งใส เหลือง / ส้ม / แดง วาดจากลมอ่อนไปแรง |
| `track` | LineString | เส้นทางที่ผ่านมาแล้ว | เส้นทึบ |
| `forecast` | LineString | จากตำแหน่งล่าสุดไปตามเส้นทางคาดการณ์ | เส้นประ |
| `track_point` | Point | ตำแหน่งแต่ละช่วงเวลา: `time` (UTC), `forecast`, `latest` (ตำแหน่งล่าสุด) | จุดเล็ก · ไอคอนพายุที่ `latest = true` · แสดงเวลาเป็นเวลาไทยเมื่อแตะ |

ทุก feature มี `event_id`, `event` (เช่น `CHAMPI-26`) และ `name`

## คลื่นทะเล (ลูกศร) — `/v1/map/overlays/waves`

จุดกริดทุก 0.5° ในทะเลอันดามันและอ่าวไทย (เฉพาะจุดในทะเล ~400 จุด, ~95 KB) ค่าคือคลื่นสูงสุดใน 24 ชม. ข้างหน้า

```json
{"type": "Feature", "geometry": {"type": "Point", "coordinates": [101.5, 9.5]},
 "properties": {"height_m": 3.2, "level": "WARNING", "direction_from_deg": 30, "direction_to_deg": 210,
                "period_s": 6.5, "peak_time": "2026-10-23T03:00:00+07:00"}}
```

- **ทิศลูกศร:** ใช้ `direction_to_deg` (ทิศที่คลื่นวิ่งไป, 0 = ไปทางเหนือ ตามเข็มนาฬิกา) กับ `icon-rotate` ของ MapLibre และตั้ง `icon-rotation-alignment: map`
- **แรง/ไม่แรง:** ใช้ `level` (มาจาก `rules.yaml` เดียวกับระดับคลื่นรายอำเภอ)

| `level` | ความสูงคลื่น | สี (จาก `LEVELS`) | ความหมาย |
|---|---|---|---|
| `NORMAL` | ต่ำกว่า 2 ม. | เขียว | คลื่นไม่แรง |
| `WATCH` | 2–3 ม. | เหลือง | เรือเล็กควรงดออกจากฝั่ง |
| `WARNING` | 3–4 ม. | ส้ม | คลื่นแรง |
| `CRITICAL` | 4 ม. ขึ้นไป | แดง | คลื่นแรงมาก |

- แนะนำขนาดลูกศรตาม `height_m` และซ่อนชั้นนี้เมื่อซูมเข้าไปในแผ่นดินลึก ๆ ได้
- แผนที่คลื่นของ สสน. (ภาพนิ่ง ไม่มีพิกัด) ยังอยู่ในแผง "ภาพเรดาร์และแผนที่คาดการณ์" (`/v1/media`)

## ฝุ่น PM2.5 และเรดาร์

มีในแท็บ "ไฟและฝุ่น" และ "ฝนและพายุ" แล้ว (`stationFeatures` และ `RADAR_LAYERS` ใน `Dashboard.tsx`) ใช้โค้ดเดิมเปิดในหน้า "ภาพรวม" ได้เลย
สีสถานีใช้ `PM25_BANDS` ของกรมควบคุมมลพิษใน `lib/api.ts`

## ข้อเสนอการแสดงผล

- ปุ่ม "ชั้นข้อมูล" มุมแผนที่ เปิด/ปิดทีละชั้น · ค่าเริ่มต้น: สีความเสี่ยง + เรดาร์ + พายุ (ถ้ามี) · ชั้นอื่นผู้ใช้เปิดเอง
- legend สั้น ๆ ใต้แผนที่เฉพาะชั้นที่เปิด พร้อมเวลาข้อมูลและแหล่งที่มา
- ชั้นที่ `status = pending` ให้แสดง "กำลังโหลด…" แล้วถามใหม่ · `unavailable` ให้ปิดปุ่มชั้นนั้นพร้อมเหตุผล
