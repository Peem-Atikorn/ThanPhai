# ที่มาและสิทธิ์การใช้ภาพพื้นหลัง

ตรวจบันทึกการจัดทำภาพ: 22 ตุลาคม 2026

ภาพทั้งสี่เป็นภาพประกอบบรรยากาศ ไม่ใช่ข้อมูลตรวจวัด ภาพข่าว หรือภาพเหตุการณ์ปัจจุบัน
ข้อความกำกับนี้แสดงอยู่ในหน้าเว็บด้วย และไม่เกี่ยวกับเครดิตของชั้นข้อมูลแผนที่/เรดาร์ซึ่งยังใช้ที่มาเดิม

## แหล่งที่มา

| ไฟล์ | ที่มาตามหลักฐานที่มี | สถานะสิทธิ์ |
| --- | --- | --- |
| `thanphai-coast.webp` | สร้างด้วยเครื่องมือสร้างภาพ OpenAI ในแชทจัดทำหน้าเว็บนี้ ตามคำสั่งผู้ใช้ | Output ที่สร้างให้ผู้ใช้; ไม่ได้ประกาศเป็น CC0 หรือ Creative Commons |
| `thanphai-fire.webp` | สร้างด้วยเครื่องมือสร้างภาพ OpenAI ในแชทนี้ เป็นภาพป่าเขาไฟไหม้ แล้วผู้ใช้บันทึกเป็น `fire-background.png` และอนุญาตให้นำลงเว็บ | Output ที่สร้างให้ผู้ใช้; ไม่ได้ประกาศเป็น CC0 หรือ Creative Commons |
| `thanphai-flood.webp` | ผู้ใช้ส่งไฟล์ `flood-background.png` จากเครื่องเพื่อใช้กับหมวดน้ำท่วม | ผู้ใช้อนุญาตให้นำลงเว็บ แต่ยังไม่มีหลักฐานแหล่งผลิต/ใบอนุญาตจากผู้สร้างแนบมา ต้องให้เจ้าของไฟล์ยืนยันก่อนระบุสิทธิ์เผยแพร่ต่อ |
| `thanphai-storm.webp` | ผู้ใช้ส่งไฟล์ `003` (ไฟล์ภาพไม่มีนามสกุล) จากเครื่องเพื่อใช้กับหมวดฝน/พายุ | ผู้ใช้อนุญาตให้นำลงเว็บ แต่ยังไม่มีหลักฐานแหล่งผลิต/ใบอนุญาตจากผู้สร้างแนบมา ต้องให้เจ้าของไฟล์ยืนยันก่อนระบุสิทธิ์เผยแพร่ต่อ |

สำหรับภาพที่สร้างด้วย OpenAI: [Terms of Use – Content](https://openai.com/policies/terms-of-use/)
ระบุสิทธิ์ใน Output ระหว่างผู้ใช้กับ OpenAI ตามที่กฎหมายอนุญาต และกำหนดให้ผู้ใช้รับผิดชอบสิทธิ์ใน Input;
ไม่ได้รับรองว่าภาพมีลิขสิทธิ์แต่ผู้เดียวหรือไม่มีสิทธิ์ของบุคคลอื่นเกี่ยวข้อง
เอกสารนี้บันทึกที่มา ไม่ได้ออกใบอนุญาตใหม่แทนเจ้าของภาพ และใบอนุญาตของโค้ดไม่ควรถูกตีความว่าครอบคลุมภาพโดยอัตโนมัติ
