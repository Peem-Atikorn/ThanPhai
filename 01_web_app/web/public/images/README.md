## ภาพหน้าภาพรวม: อนุสาวรีย์ชัยสมรภูมิ

- ไฟล์: `thanphai-victory-monument.webp`
- ภาพต้นฉบับ: [Victory Monument in the Evening.jpg](https://commons.wikimedia.org/wiki/File:Victory_Monument_in_the_Evening.jpg)
- ผู้สร้าง: samfotograf (Krit Jantana / IPhi044), ถ่ายเมื่อ 27 กรกฎาคม 2022
- สิทธิ์: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); ไฟล์ภาพที่ปรับขนาดนี้เผยแพร่ภายใต้สิทธิ์เดียวกัน
- การเปลี่ยนแปลง: แปลงเป็น WebP กว้าง 2200 px, quality 84; การลดความอิ่มสี เพิ่มความสว่าง และไล่สีทับทำผ่าน CSS โดยไม่เปลี่ยนเนื้อหาภาพ
- ใช้เฉพาะหน้าภาพรวม เป็นภาพประกอบบรรยากาศ ไม่ใช่สถานการณ์ปัจจุบัน

- พื้นที่ด้านขวาของหน้าภาพรวมใช้ส่วนท้องฟ้าด้านบนของภาพต้นฉบับเดียวกัน จัดกรอบและซ้อนสีฟ้าอมเทาด้วย CSS เพื่อให้ต่อเนื่องกับภาพอนุสาวรีย์ด้านซ้าย
